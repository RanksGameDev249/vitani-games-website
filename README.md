# ViTaNi Games — Website

A responsive static website prepared for GitHub Pages.

## Files
- `index.html` — homepage
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation and current year
- `privacy.html` — starter privacy notice
- `terms.html` — starter terms page
- `assets/favicon.svg` — site icon

## Before publishing
1. Replace `REPLACE_WITH_OFFICIAL_EMAIL` in `index.html` with the official company email.
2. Add the official phone number, registered/operating address, social links, and legal entity details if you want them displayed. Do not publish unverified details.
3. Confirm that the company name and product descriptions match your official records.
4. Review and customize `privacy.html` and `terms.html` for the actual data practices and applicable legal requirements. These are starter templates, not legal advice.
5. Verify the Google Play link and product details.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `vitani-games-website` (or another name you prefer).
2. Extract this ZIP on your computer.
3. Open the extracted folder. Upload the **contents** of this folder (not the outer folder itself) to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/vitani-games-website/`
8. Open the URL in a private/incognito browser window and test all links on mobile and desktop.

## Startup India application note
Use the live HTTPS website URL in the website field only after it is published and you have checked that it opens publicly. A website URL by itself does not establish Startup India recognition or guarantee approval. Ensure the site accurately represents the applicant entity and its real activities.
